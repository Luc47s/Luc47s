# Hola 👋

Construyendo herramientas SaaS que ayudan a negocios a automatizar reservas y atención al cliente.

Actualmente estoy desarrollando un sistema de reservas online para salones de belleza que permite a las clientas reservar turnos sin tener que escribir por WhatsApp.

## 🚀 Proyecto actual

Sistema SaaS que permite a los salones dejar de agendar turnos por WhatsApp y gestionar reservas online mediante un link.

Permite:

• Reservas online mediante un link  
• Selección de servicio, fecha y hora  
• Confirmación automática de turnos  
• Panel de gestión para el salón  
• Posibilidad de pedir seña para evitar cancelaciones

La activación del sistema toma menos de 2 minutos.

## 💻 Tecnologías

Trabajo principalmente con:

• JavaScript  
• Node.js  
• Automatización de workflows  
• Integraciones con APIs


## 🎯 Objetivo

Construir herramientas simples que ayuden a negocios a automatizar tareas repetitivas y ahorrar tiempo.
